# Transferencia ejecutada sin pago acreditado

## Cuándo consultar esta guía

El sistema muestra la transferencia como ejecutada, pero el beneficiario no recibió el pago.

## Procedimiento indicado por la fuente

La fuente asigna a MDA una validación inicial con GIRE. Confirmar que ese contacto y recorrido continúen vigentes.

## Datos para continuar el análisis

La fuente no detalla qué comprobantes, identificadores o plazos recopilar. Completar esta lista con el equipo responsable antes de publicar la ficha como procedimiento operativo.
