# Inconsistencia al crear o volver a registrar un suscriptor

## Cuándo consultar esta guía

El alta informa que los datos ya existen, o el suscriptor no puede iniciar una nueva suscripción después de eliminar una anterior.

## Procedimiento

1. Confirmar si existió una suscripción previa, incluso si quedó incompleta o fue eliminada.
2. Si el caso coincide, solicitar a MDA que genere un caso para Soporte, que revisará la inconsistencia y realizará la regularización correspondiente.
3. No pedir pruebas genéricas de caché o navegador para este caso: la fuente indica que no resuelven esta condición.

## Escalamiento

La limpieza de residuos y habilitación requieren intervención de Soporte. No realizar cambios manuales.
