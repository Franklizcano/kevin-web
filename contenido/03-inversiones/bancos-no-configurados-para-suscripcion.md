El caso se presenta cuando el cliente no puede realizar suscripciones porque no tiene cargado el/los banco/s y visualiza algo como esto.

![Imagen original del documento]({{ '/assets/originales/bancos-no-configurados-para-suscripcion/captura-01.jpg' | relative_url }})

No es un error, al cliente le falta o no tiene configurado el/los banco/s en la base de inversiones, se realiza por script mediante Soporte con caso por CRM.

El caso debe llegar a Soporte por CRM, con:

Cuit

Razón social

Abonado

Bancos que requiere el cliente

no es necesario la captura de pantalla.
