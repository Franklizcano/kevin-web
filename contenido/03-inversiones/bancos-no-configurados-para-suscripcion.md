# No están configurados los bancos para suscribir

## Cuándo consultar esta guía

El cliente no puede iniciar una suscripción porque no tiene bancos configurados en la base del módulo de Inversiones.

## Resolución

La fuente indica que la configuración la realiza Soporte mediante una tarea técnica. No es un error que el usuario final pueda corregir desde la pantalla.

## Datos para continuar el análisis

El caso original pide identificar la empresa y los bancos que requiere. Enviar esos datos únicamente mediante el canal interno autorizado. La fuente indica que no necesita captura de pantalla.

## Escalamiento

La fuente indica derivación a Soporte mediante CRM. Confirmar que CRM y el procedimiento continúen vigentes.
