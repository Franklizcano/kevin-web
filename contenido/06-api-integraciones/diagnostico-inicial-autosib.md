# Diagnóstico inicial de AUTOSIB

## Cuándo consultar esta guía

El cliente informa problemas de conexión, errores de acceso, cortes o reinicios del servicio AUTOSIB.

## Verificaciones iniciales

1. Determinar si hay indicios de una falla general o si el problema se presenta en un único entorno. La fuente indica que una falla general suele generar múltiples reportes o alertas.
2. Solicitar una reinstalación del software AUTOSIB y volver a probar la conexión, si el procedimiento vigente lo permite.
3. Si los registros muestran errores de SSL, conexión o reinicio, revisar junto con el cliente el Visor de eventos y los cambios recientes de configuración o del sistema.

## Evidencia para escalar

Recopilar registros relevantes, momento de inicio, alcance del problema y resultado de las pruebas. No adjuntar registros con credenciales, certificados privados ni datos ajenos al diagnóstico.

## Alcance de las fuentes

Las dos guías se complementan: una desarrolla la evidencia y las pruebas de conexión; la otra resume el diagnóstico inicial para el equipo de atención. Aplicar las verificaciones anteriores y derivar con los registros pertinentes por el circuito de soporte de AUTOSIB.
