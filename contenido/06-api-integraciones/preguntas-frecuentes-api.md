# Preguntas frecuentes de API

## Alcance que describe la fuente

- El portal de API contiene la documentación funcional y los estados/respuestas disponibles.
- El flujo descrito permite confeccionar transferencias por API; la autorización y el envío se realizan desde la plataforma web o la aplicación.
- La fuente plantea consultas sobre cómo se muestran errores al cargar datos incorrectos y qué valores puede devolver el campo de estado.

## Antes de responder

Consultar el catálogo oficial de API vigente. La fuente es una lista de preguntas y respuestas incompleta; no utilizarla para publicar una lista de estados, códigos o respuestas sin validarlos contra la documentación actual.

## Consultas y derivación

La fuente diferencia consultas comerciales o de soporte de implementación de las consultas que deben coordinarse con Desarrollo. Confirmar los contactos y el circuito actuales antes de publicar.
