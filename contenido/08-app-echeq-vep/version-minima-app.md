# Versión mínima para instalar la app

## Versiones indicadas

- Android: 9.0 o posterior.
- iOS: 15.1 o posterior.

## Si la instalación sigue fallando

Registrar el modelo del dispositivo, sistema operativo y mensaje visible, evitando recopilar datos que no sean necesarios. La fuente no define pasos adicionales de resolución.
