# Notas editoriales

Las fuentes entregadas fueron revisadas y organizadas en fichas por tema. El índice prioriza el síntoma y el módulo para facilitar la consulta.

## Criterios de organización

- “Errores de referencia en SIB” aparecía en Cuentas y Offerings; se presenta una sola vez como ficha canónica.
- Las dos guías de AUTOSIB se reúnen en una misma ficha.
- El ZIP repite la estructura documental y se considera respaldo del material, no una fuente editorial independiente.
- El documento de reglas de negocio se incorporó como referencia técnica de formatos DATANET y SAP, separado de los casos de troubleshooting.

## Fuente técnica de archivos generados

“Archivos Generados - Reglas de negocio V7 con CVU” es un documento Word legado. Su versión 7.0 conserva un historial desde 2005 hasta el 26/11/2019, incluida la incorporación del formato de transferencias ejecutadas con CVU. La ficha web resume su alcance y remite a la especificación original para los diseños de registro. El contenedor OLE del archivo incluye un proyecto VBA; no se ejecutó contenido activo durante el análisis.

## Consideraciones de publicación

GitHub Pages público es accesible para cualquier persona con la URL; los permisos del repositorio no restringen a los visitantes del sitio. Antes de publicar, no incluir datos reales de clientes, identificadores, credenciales, claves privadas, registros de consola ni consultas o scripts internos. La documentación fuente puede contener ese tipo de detalles.
